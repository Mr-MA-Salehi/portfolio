# Mohammad Arif Salehi: Portfolio

Static portfolio website (HTML, CSS, JavaScript). No build step.

- Pages: Home, About, Services, Project (AirAssist AI), Community, Certificates, Contact
- Live demo of the featured project: https://airassist-ai-website.vercel.app
- Project source code: https://github.com/Mr-MA-Salehi/airassist-ai-website

## Hosting (free)

- **Render Static Site:** connect this repository, leave the build command empty (or `echo ok`), set the publish directory to `.`
- **GitHub Pages:** Settings > Pages > Deploy from branch > `main` / root
- **Vercel / Netlify:** import the repository, no build settings needed

Replace `Mohammad_Arif_Salehi_CV.pdf` when the CV changes.
